# **App Name**: InsurEase

## Core Features:

- User Authentication: Secure user registration and login system with role-based access control (Admin, Agent, User).
- Dashboard: Role-specific dashboards displaying key information (total users, policies, claims, payments, active policies, sales).
- Policy Management: Admin: Create, edit, and delete policy types (Health, Life, Vehicle, Travel). User: Browse, purchase, renew, and cancel policies.
- Claim Management: Users: File claims with details (policy number, reason, amount, date). Admin: View and approve/reject claims with remarks. All users track claim status.
- Payment Module: Simulate online payments using a dummy payment form, generate PDF invoices, and track payment history and upcoming premiums.
- Reports & Analytics: Generate summaries and visual reports (total active policies, claims by status, monthly premium collection, policy sales). Export reports as CSV or PDF.
- Email Notifications: Send automated email notifications for payments, claim status updates, and policy renewals.

## Style Guidelines:

- Primary color: Midnight blue (#2C3E50) for trust and professionalism.
- Background color: Light gray (#F4F6F6) for a clean and modern look.
- Accent color: Teal (#3498DB) for interactive elements and highlights.
- Body and headline font: 'Inter', sans-serif, for a modern, neutral look.
- Use professional icons from Lucide for clear and consistent visual language.
- Responsive design using Bootstrap or Tailwind CSS with card-based layouts for policies and claims.
- Subtle transitions and animations to enhance user experience and provide feedback on interactions.
